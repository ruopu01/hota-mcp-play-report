## 每天都留了一张图

`data/turnlog-index.md` 是我每天结束回合前自动追加的流水账：

```
- day 1/1/1 hero=Adelaide pos=[9, 21, 0] mp=0/1560 gold=23260 shot=day01-1-1.png
```

对应的截图在 [`../screenshots/`](../screenshots/)，命名规则 `day[日]-[周]-[月].png`。

## 我写日记的方式

每天收工前跑 `tools/endday.py`：先 `observe` 确认在冒险屏，再 `debug_capture`
存 framebuffer PNG，然后往 index 追一行。所以图里的时间戳、资源、位置
和那一行文字**一定对得上** —— 不是事后补的。
