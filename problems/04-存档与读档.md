# 04 · 存档与读档：入口藏在角落里，`menu:load` 是坏的

> **严重度：🟠 中**。不至于玩不下去，但在"想回滚一次事故"的时候会要命 ——
> 我确实靠它把被打死的主英雄救回来过一次。

---

## 一、存档：冒险屏里没有 save

冒险屏（`adventure`）的 36 个动作里**没有一个存盘**。挨个试：

| 尝试 | 结果 |
| --- | --- |
| `Esc` | "Are you sure you want to quit?" —— **这是退出确认，不是菜单** |
| `game:adventure_options`（A 键） | 只有 View World / Puzzle Map / Dig / Scenario Info / Replay Opponent Turn |
| `click_ui ui:23`（右上角小按钮） | `[UNKNOWN_CONTROL]` |

### 正解：右侧面板的 `iam009.def` 小按钮

```json
{"key": "ui:10", "asset": "iam009.def", "x": 1091, "y": 356, "width": 32, "height": 32}
```

```text
click_ui ui:10 → screen = system_options
  动作：game:save / game:load / game:main_menu   ← 只有这三条
```

### 存档流程

```text
act game:save                      → screen = save_game
act save:name:fish-10              → 输入框写入（只接受窗口布局内的字母/数字/连字符）
act save:confirm                   → message 屏："fish-10 saved successfully."
act message:accept                 → 关闭
```

**注意两个坑**：

1. 存档列表当前选中的是 `111.GM1`（上一次的自动命名），直接 `save:confirm`
   会**覆盖**它。必须先 `save:name:` 命名。
2. 保存成功的 `message` 屏对 `message:confirm` 报 `[UNKNOWN_CONTROL]`，
   要用 `message:accept`。

落盘位置（比想象的深一层）：

```
...\Games\HotA Random\2026.11.02 19;34 {Default}\fish-10.GM1     37,156 字节
                      └─ 地图名          └─ 存档时间戳文件夹
```

## 二、读档：`menu:load` 会把你送到"新游戏"菜单

主菜单上 `LOAD GAME` 是第二个按钮（`mmenulg.def`，矩形 746,176,186×107）。

```text
act menu:load                                    → screen = game_type   ← 新游戏菜单！
click_ui ui:1（像素点 LOAD GAME，中心 835,229）   → screen = game_type   ← 一样！
```

语义动作和像素点击**都跳错**。这不是我点歪了，是那条路径本身接错了线。

### 真正的存档列表在 `menu:single` 后面

```text
act menu:single        → screen = scenario_selection
  动作：
    load:open:0        → Air Supremacy 文件夹
    load:open:1        → HotA Random 文件夹
    load:select:2      → AUTOSAVE
    load:select:3      → BATTLE
    load:confirm
    load:back
```

```text
act load:select:2      → uncertain（但选中其实生效了）
act load:confirm       → 读档成功，回到 AUTOSAVE 那一刻
```

### 实测回滚

第一版第二局第 8 天，20 只 Genie 把主英雄 Adelaide 打死了（`combat:auto` 全灭）。
`load:select:2` + `load:confirm` 回到第 7 天结束时：

```
金 24,590   Adelaide (12,6) mp 0  42/13/8/7
Rion (8,12) mp 629    Armitage built 6
```

**注意：读档后随机数也回滚了。** 重打同一天，难民营的商品从"6 只铁皮人"
变成了"4 个剑士"——这反倒救了我：剑士比铁皮人有用。

---

## 三、建议（如果作者看到）

- 冒险屏加一个 `game:save` 动作（现在必须先进 `system_options`）；
- 修 `menu:load` 的路由（现在它和 `menu:new` 撞了）；
- 读档列表暴露成 `save:select:<name>` 而不是靠位置索引 —— 索引会随存档数量变化。
