## 问题 11：静默安装直接 `exit 2`，什么也不说

### 现象

```powershell
PS> .\HotaMcp-Setup-1.0.2.exe /S /D=D:\Heroes3\HotaMcp
PS> $LASTEXITCODE
2
```

安装目录根本没被创建，没有任何对话框（`/S` 是静默）。事件日志里只有一条
`Windows Installer installed the product`——不，什么都没有，因为它是 NSIS，不是 MSI。

### 定位

解开安装包看脚本（`tools/installer/hota-mcp.nsi`）：

```nsis
; :129-133  安装前必须同时找到这三个文件
IfFileExists "$INSTDIR\h3hota HD.exe" +2 0
  ...
IfFileExists "$INSTDIR\HotA.dll" +2 0 ...

; :199-205  静默模式下校验失败就 Abort
${If} ${Silent}
  SetErrorLevel 2
  Abort "Папка игры не найдена"
${EndIf}
```

而 `.onInit` 里找游戏目录的候选只有：

1. `HKCU\Software\HotaMcp\GameDir`
2. `HKLM\SOFTWARE\GOG.com\Games\1207658787\path`
3. 各盘符下的 `HoMM 3 Complete` / `Games\HoMM 3 Complete` / `GOG Games\HoMM 3 Complete`

我的游戏装在 `D:\Heroes3\Heroes of Might and Magic 3 Complete Edition GOG\Heroes of Might and Magic 3 Complete`
—— **三条都不匹配**，于是 `$INSTDIR` 是空，校验失败，`Abort`，退出码 2。

### 绕法

```powershell
reg add "HKCU\Software\HotaMcp" /v GameDir /t REG_SZ /d "<游戏目录>" /f
.\HotaMcp-Setup-1.0.2.exe /S /D=D:\Heroes3\HotaMcp
```

预置注册表后一次成功。**教训**：静默安装器不告诉你它缺什么，看 `.nsi` 比看日志快。

## 问题 12：`attach` 失败，五项结构自检三项不过

### 现象

游戏起来了、进程在、窗口也在，但 `game_status` 一直：

```json
{
  "state": "attachment_error",
  "detail": "Structures this adapter needs were not found: \
             window manager — manager pointer is not a pointer; \
             surface geometry — Invalid game layout; \
             manager list — executive pointer is not a pointer"
}
```

### 根因

第一次是在一份国产整合包上试的：`HotA.dll` 显示 1.8.1，但 **HD Mod 只有 5.2**
（`HD_LauncherNative.dll` 5.2.0.0 / `HD_HOTA.dll` 5.0.0.2，2022 年）。
hota-mcp 1.0.2 要的是 **HD Mod 5.8**——它读的那个"管理器指针在 `0x6992d0`、
对话框在 `+0x54`"的结构，是 5.8 才稳定的布局。

换成干净的 Hack of the Abyss 1.8.1 + HD Mod 5.8 R22 后：

```
state: attached   build.status: compatible
"Every structure this adapter uses was found in place"
  window manager   active dialog class 0x63ff60
  surface geometry 1180x664
  hero array       record stride 0x492, offset 0xfdbd0000
  town entry       town array offset 0x21614
  manager list     2 managers
```

### 顺带两个坑

- **`HotA.dll` 时间戳新 ≠ 版本新**：官方 1.8.1 的 `h3hota.exe` 时间戳仍是 2023-07-27，
  版本号住在 DLL 里。别用 exe 日期判断版本。
- **`start_game` 工具不是"启动游戏"**：非 HD Launcher 托管时它会返回
  `Server must be hosted by HD Launcher to start the game`。
  正确姿势是自己 `Start-Process "h3hota HD.exe"`，服务会自己 attach。
  `--launch` 那条路会同时起 launcher + MCP 标签页 + 游戏，但依赖 `hotamcp-launcher-tab` 插件，
  我这边没跑通（服务 11 秒后自退、没有 `launch.log`）。
