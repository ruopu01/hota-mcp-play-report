## 通用自救手册

```text
1) 每次动作前重新 observe 拿新 revision（STALE_REVISION 42 次全是因为这个）
2) uncertain ≠ 失败：先 observe 复核，再决定要不要重试；绝不换新 operationId 重复同一件事
3) 语义动作被拒且报 UNKNOWN_CONTROL → 改用像素点击 / 键盘 Enter / Esc
4) NO_PATH 且 read_map 显示可走 → 改用 hero:step 一格一格走
5) 屏幕不对 → 先 screen:close 或 Esc，再动作
```
